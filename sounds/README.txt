Drop your sound files here with EXACTLY these filenames:

  coin-flip.mp3       — played when the coin is flipped (full sound, any length)
  swing-gentle.mp3    — gentle swing (≤10% power)
  swing-medium.mp3    — medium swing (20–40% power)
  swing-strong.mp3    — strong swing (50–70% power)
  swing-max.mp3       — full-power swing (80–100% power)

If a file is missing the game falls back to a synthesized sound automatically.
Supported formats: mp3, wav, ogg (anything the browser can play).
